# Capitaine Ad’Hoc — Site (Vue 3 + Vite + Tailwind)

Single-page site with all cleaned-up content extracted from the provided PDF.
- Black & white only
- Squared design (no rounded corners)
- Marine life SVG logo
- Anchor navigation for each section

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
